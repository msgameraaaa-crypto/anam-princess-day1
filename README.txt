ANAM - PRINCESS DAY WEBSITE

Files:
- index.html: website structure
- style.css: design and responsive styling
- script.js: surprise-letter button interaction
- assets/: Anam's four photos

To publish with GitHub Pages:
1. Create a new public GitHub repository.
2. Upload index.html, style.css, script.js, and the assets folder.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish; your site URL will appear there.

Note: JavaScript is written in script.js (not Java).
